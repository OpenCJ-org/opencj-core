# Security reports

Do not put credentials, database dumps, player identifiers, private moderation
rules or exploitable details in a public issue. This local repository does not
yet have a verified private reporting endpoint. Before public hosting, the
maintainer must enable a private reporting channel and replace this notice with
its verified address or repository security-advisory link.

Keep operational credentials outside Git and restrict access to local backups.
If a credential was exposed, replacing it is necessary; deleting the file or
rewriting history does not revoke it.
