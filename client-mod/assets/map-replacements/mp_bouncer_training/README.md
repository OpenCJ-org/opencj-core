# Bouncer Training picture replacements

`missing-picture.svg` is the original vector source for the dark question-mark
placeholder. `missing-picture.png` and the two `.iwi` files are generated by
`dev-tools/scripts/build-bouncer-art.py` on the authoritative server.

The map uses `christina.iwi` for its repeated wall pictures and
`compass_map_mp_bouncer_training.iwi` for a decorative photo rather than a real
map diagram. Both are replaced. The loading image is maintained separately in
`client-mod/assets/map-previews/mp_bouncer_training-start.png`.

These files change artwork only; map fastfiles, geometry and gameplay stay intact.
