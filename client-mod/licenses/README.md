These files identify specific third-party inputs:

- `flag-icons.txt`: flag-icons v7.5.0, MIT.
- `db-ip.txt`: DB-IP Lite data attribution, CC BY 4.0.
- `pixabay-audio.txt`: route-finish sound creators, source URLs and Pixabay Content License.
- `map-previews.txt`: mapper credits, source links and the recorded map-preview licensing status.

Matching copies live under `../cod4/licenses/` so client builders include them
in `z_opencj.iwd`. The Lucide 0.468.0 notice also lives there and in the optional
Oldschool export. Preserve those notices with the corresponding assets.

See [licenses and asset sources](../../docs/reference/licensing.md) for component
licenses, external tools and unresolved material. A notice for one asset does
not license other assets in the package.
