# The OpenCJ beta is here
Version: beta-0.1.0
Released: 2026-11-23

The first public beta of OpenCJ, the open-source CoDJumper mod for Call of Duty 4.
All 10 maps in the beta map pool are checkpointed, and more maps will slowly be
added over time.

## Runs and rankings
- Timed runs with checkpoints along the way, and several routes per map, such as easy, inter and hard
- Leaderboards per route, filterable by FPS mode (125, mix, hax), elevators, shortcuts, halfbeat and TAS
- Challenges in tiers: completed challenges earn points, and the Top 10 ranks the most skilled players
- Save and load positions, with a save history to go back to earlier saves

## Checkpoint creation tooling
- An in-game checkpoint editor for mappers and admins: draw routes, mark finish areas and publish them
- Alternative landing areas, moving platforms and shared sections between routes
- Drafts are saved, so a route can be built over several sessions before it goes live

## Learning and watching
- Tutorial mode for new players, which sets the right FPS for each jump automatically
- Demos of runs that can be watched in game, plus short clips to share
- HUDs for FPS, FPS history, speed, keys and spectators

## Server and community
- Map voting and a map browser with mapper credits
- A searchable command browser: type `!help`
- Preferred player names and country flags on the scoreboard
- The OpenCJ website with release notes, server status, rankings and map downloads

## Not included yet
- The shop is a preview only. Challenge points are already earned and saved, but items cannot be bought or equipped yet.
