Guide

OpenCJ is a CoDJumper mod for Call of Duty 4. The goal of every map is to reach the end using CoD4 movement: bounces, FPS changes and rocket jumps.

How to join
  • Start Call of Duty 4 multiplayer.
  • Open the console and type {{ connect_command(connect_address, "guide-connect-command") }}
  • Every pool map is also available from the downloads page.
  • New players start with a short tutorial.
Challenges and the Top 10

Challenges ask you to finish a route under set conditions, such as a time limit or a maximum number of rockets. Each completed challenge earns points, and harder tiers are worth more.

The Most skilled players ranking adds up the points of all active challenges you completed. It is the same ranking as the in-game Top 10. Players with equal points share a position.

Map leaderboards

Every route has its own leaderboard of fastest finishes. The website shows the in-game default view: runs without elevators, shortcuts, halfbeat or TAS, in any FPS mode, with each player's best run.

The FPS column shows the run's FPS mode: 125, mix (the standard mode) or hax (all FPS values).

Tutorial runs never count towards rankings.
