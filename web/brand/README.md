# OpenCJ logo

The letters C and J with a player jumping from the C onto the J. The word OPEN
follows the jump's arc and fades through the FPS colors: cyan (125), white
(250) and periwinkle (333).

| File | Use |
| --- | --- |
| `opencj-logo.svg` | Square tile with the dark background; source for avatars |
| `opencj-logo-512.png`, `opencj-logo-1024.png` | Discord server icon and other avatars |
| `opencj-logo-mark.svg` | The mark without background, for dark surfaces |

The website uses copies in `web/opencj_web/static/`: `logo-mark.svg` in the
navigation, and `favicon.svg`, `favicon-32.png` and `apple-touch-icon.png` as
browser and phone icons. Discord crops avatars to a circle; all parts of the
mark stay inside it.

## Rebuild

All files are generated by [build_logo.py](../tools/build_logo.py). Edit the
geometry or colors there, never the SVG or PNG files by hand. The script needs
Python with fontTools and CairoSVG (with the Cairo library) and the Chakra
Petch Bold font file:

```sh
python3 web/tools/build_logo.py --font /path/to/ChakraPetch-Bold.ttf \
    --static-dir web/opencj_web/static --brand-dir web/brand
```
